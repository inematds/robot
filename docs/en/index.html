What changed in the 2026 edition

The course has been rebuilt from scratch. Robotics tutorials become outdated quickly; here are the places where the old material no longer worked.

ESP32 with API 3.x

All code uses Espressif’s esp32 3.x package, with the new PWM (ledcAttach / ledcWrite using the pin).

Raspberry Pi 5

Raspberry Pi OS 64-bit, camera access through picamera2 and AI acceleration with the AI HAT+.

YOLO26

Object detection with the current Ultralytics release, exported to NCNN to run quickly on the Pi.

ROS 2 Lyrical and Jazzy

The two current LTS releases, with the newer Gazebo, slam_toolbox and Nav2. The commands work the same on both.

LeRobot and SO-101

An open-source arm that learns from demonstrations, with policies such as ACT and SmolVLA, plus language AI running locally.

No set study schedule

Learn as needed, with saved progress, notes, and a full module for anyone who will teach the course.

T5 Modern AISO-101 arm (printed parts and Feetech servos), USB microphone and speaker, Pi 5 or a computer with a GPU for training.
